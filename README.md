Informatics Engineering student at **UIN Sunan Gunung Djati Bandung**. I build full-stack web apps and machine learning / computer vision systems, and I care about evaluating them honestly — including when the result is "it doesn't work".

- **Now:** final-year thesis on fall detection from skeleton pose (MediaPipe + hybrid LSTM–SVM), started during a research internship at **Universiti Sains Malaysia** (July 2026).
- **Interests:** computer vision, ML evaluation and reproducibility, backend systems.
